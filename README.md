# Le Chat Noir

Landing page responsive hecha con React y Vite para una cafetería ficticia. Incluye navegación móvil, filtros del menú, precios, calorías aproximadas y formulario local de reservación.

## Ejecutar

1. Abre una terminal en esta carpeta.
2. Ejecuta `npm install`.
3. Ejecuta `npm run dev`.
4. Abre la dirección local que mostrará Vite.

Para crear la versión de producción, usa `npm run build`.

## Organización

- `src/main.jsx`: interfaz, datos del menú e interacciones.
- `src/styles.css`: estilo responsive y diseño visual.
- `public/logo.png`: logo proporcionado para la marca.
